Move TV Box Generator Lozinke za Developer Options

Izračunaj lozinku za USB otklanjanje grešaka / developer opcije za Android TV box (com.android.tv.settings) na osnovu serijskog broja. Sve se izvršava u vašem pretraživaču — ništa se ne šalje nigde.

Kako radi
Rekonstruisano iz klasa PwdVerify, AESUtils i KeyGen u aplikaciji:
  1. plainText = serijskiBroj + "ed12a270c07a58074126a0487de27f63"
  2. AES ključ = PBKDF2-HMAC-SHA1(plainText, salt="sdmc", 10000, 128-bit) → 32 hex karaktera, korišćeno kao sirovi ASCII bajtovi (AES-256)
  3. enc = Base64( AES-256/ECB/PKCS5( plainText ) )
  4. lozinka = (enc[0:3] + enc[-3:]).toLowerCase()
Pretraživači nemaju AES-ECB, pa ova stranica izvodi svaki ECB blok iz jednoblokovnog AES-CBC sa nultim IV (matematički identično).

Ako lozinka bude odbijena: proverite serijski broj (bez izostavljenih ili viška karaktera). Neki uređaji koriste drugačiji interni serijski broj (ro.boot.serialno) od onog prikazanog na ekranu. Postoji i OEM override — ako je bezbednosno podešavanje security_symbol postavljeno (≥6 karaktera), ta vrednost je lozinka umesto izračunate i ne može se izračunati ovde.
